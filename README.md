Semantic Search Engine using Transformer Embeddings

Overview
--------
Browser-based semantic search application using NLP embeddings.

Architecture
------------
User Query
 ↓
Transformer Encoder
 ↓
Embedding Vector
 ↓
Cosine Similarity
 ↓
Ranked Results


Technologies
------------
- JavaScript
- Transformers.js
- Sentence Transformers
- Vector Similarity
